# Money Log

나만의 용돈 및 지출 관리 웹 프로그램입니다.

## 주요 기능
- 이번 달 예산 설정
- 지출 항목 및 금액 기록
- 카테고리별 지출 확인
- 지출 내역 검색 및 삭제
- 예산 사용률 표시
- 브라우저 LocalStorage를 이용한 자동 저장

## 실행 방법
`index.html` 파일을 웹 브라우저에서 열면 실행할 수 있습니다.

## GitHub Pages 배포
1. 이 저장소의 Settings 메뉴를 엽니다.
2. Pages 메뉴로 이동합니다.
3. Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
5. 배포가 완료되면 Pages 화면의 Visit site에서 웹사이트를 확인합니다.
